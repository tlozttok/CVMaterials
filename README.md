# CVMaterials

这份材料对应一份简历里出现的每一处方括号引用 `[n]`。

简历的主张是「品质可以用对话语料实证」，所以这里把每条主张的原始出处摊开：本人原话是什么、出现在哪次会话的第几个节点、以及哪一处其实只是我自己的推测。用法只有一条：**怀疑哪一句，就打开哪一条，原文一字未改。**

## 怎么读

- 一处引用一个文件，命名 `L行号-序号_首个会话号.md`，例如 [`片段/L42-1_7effc167.md`](片段/L42-1_7effc167.md)。
- 每个文件顶部三行：对应简历正文第几行、它支撑的那一句、会话标题与节点号；下面是引用块。
- 引用块分角色标注：`· 用户` 是本人原话，`· AI` 是模型输出。两者不混排，没有把 AI 的话记在人名下。
- 节点号是原始导出 JSON 里 `mapping` 的键，与简历正文方括号里的数字一致，可回原文件逐条核对。
- 覆盖范围：**32 处引用、70 个原始节点**。简历 34 个脚注里，`[2]` 是统计口径、`[9]` 有一半指向仓库文件，其余全部落到这里。

## 两处证据不来自语料

**竞赛。** 语料里只有三条备赛痕迹：`3961380d`（2025-12-23 让 AI 讲 2025 年赛题）、`72b3f643`（2026-01-20 问 MCM C 题要准备哪些知识门类）、`1f9c4983`（2026-09-15 问 ICM 的 H 奖是什么级别）。这三条能证明准备过、关心过结果，**不能证明参赛和交卷**。所以简历里这一行不挂引用：竞赛属于第三方可核验的事实，证明责任在证书和赛果名单。

**占比。** `31.4% / 14.4%` 不是真值，是词表口径下的量级，算法与三种口径的对照见 [`口径/语料占比.md`](口径/语料占比.md)。同一个数换口径会翻转：把「读模型、推理、可解释」也算作学习，学习占 43.2%，高于改进的 31.4%。所以简历里写的是「取量级」——它只能支持「改进系统是我最集中的单一主题」，不能支持「我给它时间多于学习」。

## 复核

原始导出的结构是会话列表，每段会话有一个 `mapping`，键就是这里标的节点号，`fragments` 里按 `type` 区分人侧输入（`REQUEST`）与模型输出（`RESPONSE`）。拿到原始导出后，任一条都可以这样还原：

```python
import json

d = json.load(open('<conversations.json>', encoding='utf-8'))
c = [x for x in d if x['id'].startswith('7effc167')][0]
m = c['mapping']['9']['message']
print(''.join(f['content'] for f in m['fragments'] if f['type'] == 'REQUEST'))
```
